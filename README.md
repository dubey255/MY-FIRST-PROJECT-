# Sales Performance Dashboard

## 📊 Project Overview

This project is a Sales Performance Dashboard created using Microsoft Power BI.

The dashboard analyzes sales data and provides insights into revenue, orders, quantity, customers, regions, categories, products, salespersons, and order status.

## 🛠️ Tools & Technologies

- Excel – Data Cleaning and Preparation
- PostgreSQL – SQL Data Analysis
- Power BI – Dashboard and Data Visualization
- GitHub – Project Documentation and Version Control

## 📈 Dashboard Features

- Total Revenue
- Total Orders
- Total Quantity
- Total Customers
- Revenue by Region
- Revenue by Category
- Revenue by Product
- Salesperson Performance
- Monthly Revenue Trend
- Order Status Distribution

## 🔍 Key Analysis

The project includes SQL analysis such as:

- Aggregate functions
- GROUP BY
- HAVING
- ORDER BY
- CASE statements
- NULL value checking
- Duplicate checking
- Ranking using Window Functions

## 🎯 Objective

The objective of this project is to analyze sales data and create an interactive dashboard that helps understand sales performance and business trends.
